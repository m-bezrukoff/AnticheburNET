# AnticheburNET

VPN, прокси и управление маршрутизацией для OpenWrt. AnticheburNET позволяет выбирать, какие устройства, домены и IP-адреса используют защищённое подключение, выходят в интернет напрямую или блокируются. Настройки доступны в веб-интерфейсе LuCI.

Сборка рассчитана на **Xiaomi Redmi Router AX6000** и ограниченный объём flash-памяти: полный комплект включает Hysteria 2, Xray и AmneziaWG и укладывается в 40 MB установленных файлов.

| Параметр | Поддерживаемая конфигурация |
| --- | --- |
| Роутер | Xiaomi Redmi Router AX6000 |
| Система | OpenWrt 25.12 |
| Платформа | mediatek/filogic |
| Архитектура пакетов | aarch64_cortex-a53, ARMv8 |

## Подключения и подписки

- **sing-box extended 1.14.1 / 2.7.2** — Hysteria 2, XHTTP, uTLS, WireGuard и Clash API.
- **Xray 26.10.10** — отдельное полное ядро с сохранением нативных outbound-настроек, подключённое к маршрутизации через локальный SOCKS.
- **AmneziaWG 3.1** — userspace-туннель через `/dev/net/tun`, официальный daemon и инструменты настройки. Поддерживаются параметры версии 3.1 и импорт конфигурации по HTTP(S).
- **Подписки Happ** — импорт VLESS и Hysteria 2, включая ECH, с обновлением узлов и маршрутизации из одной HTTP(S)-ссылки.

Профили AmneziaWG в формате `vpn://` с Base64-кодированной `.conf` автоматически входят в общий список подписки на Dashboard: доступны выбор сервера, копирование ссылки и проверка задержки. Параметры 3.1 сохраняются полностью; каждый отдельный профиль работает через официальный daemon и собственный интерфейс с отдельной таблицей маршрутизации. Нужен установленный компонент AmneziaWG 3.1; служба профилей подписки входит в backend и обновляется вместе с LuCI через Check update. После установки обновите подписку. Сжатые JSON-контейнеры Amnezia `vpn://` этим импортом пока не поддерживаются.

Для отдельного интерфейса AmneziaWG также принимаются `.conf`, профили sing-box extended и Mihomo JSON/YAML с `amnezia-wg-option`, а также указанные `vpn://` ссылки внутри смешанной подписки. Если в подписке несколько профилей, нужно выбрать точное имя. Ошибка загрузки или проверки сохраняет рабочую конфигурацию. После обновления отдельного AWG-интерфейса примените настройки AnticheburNET или перезапустите сервис.

## Маршрутизация и DNS

Правила объединяются в секции: можно выбирать подключение для устройств, доменов и подсетей, задавать прямой выход или блокировку, использовать группы узлов с проверкой доступности и автоматическим выбором.

Маршрутизация Happ применяется вместе с подпиской: учитываются порядок Direct/Proxy/Block, глобальный выход, доменные и IP-правила, GeoIP/GeoSite, Remote/Domestic DNS и DnsHosts. Изменение только правил также обновляет конфигурацию. DNS сохраняет соответствие доменов и реальных IP для маршрутизации клиентских соединений; поддерживаются IPv4 и IPv6.

## Место на flash

В релизе **1.0.1** шесть APK устанавливают **31 183 666 байт файлов**. Консервативная оценка размещения — **32 080 690 байт** при лимите **40 000 000 байт**. В комплект входят AmneziaWG и полные базы GeoIP/GeoSite.

Бинарники упакованы UPX, встроенные базы Xray хранятся в gzip и распаковываются в RAM. Загружаемые базы маршрутизации Happ и преобразованные rule-set также размещаются в RAM. Расход оперативной памяти зависит от правил и нагрузки.

[Измерения и сравнение способов упаковки](docs/FLASH-BUDGET.md).

## Обновление программы

В разделе обновлений кнопка **«Проверить обновление»** устанавливает найденную новую версию AnticheburNET. Настройки сохраняются; перед установкой создаётся резервная копия в `/root/anticheburnet-backups`. Фоновая проверка сообщает о новой версии без установки.

## Установка

Сохраните резервную копию настроек через LuCI → System → Backup на компьютер. Войдите на роутер по SSH под `root` и выполните **одну команду**:

```sh
( f="$(mktemp /tmp/anticheburnet-install.XXXXXX)" || exit 1; trap 'rm -f "$f"' EXIT; wget -T 30 -O "$f" https://raw.githubusercontent.com/m-bezrukoff/AnticheburNET/main/install.sh && sh "$f" )
```

При запуске установщик предложит выбрать `1) install` или `2) uninstall` (также можно ввести слово `install` или `uninstall`). После выбора `install` он спросит язык интерфейса: **`1) English` — по умолчанию**, `2) Русский`. Enter выбирает английский; неверный номер повторяет вопрос. Выбранный язык сохраняется в настройке `luci.main.lang` и применяется ко всему интерфейсу LuCI. Затем установщик автоматически скачает последний релиз с GitHub, проверит SHA-256 и установит **весь комплект**: AnticheburNET, LuCI с пакетом русского перевода, sing-box extended (Hysteria 2/XHTTP), Xray и AmneziaWG. Выбор компонентов и ручное скачивание не требуются. Опции `sh install.sh --install` и `sh install.sh --uninstall` пропускают выбор действия; при установке вопрос о языке остаётся, а при отсутствии ввода используется английский. Удаление не спрашивает язык.

Нужна установленная OpenWrt 25.12 с `apk`, target `mediatek/filogic`, arch `aarch64_cortex-a53`, минимум 40 MB свободного overlay **после удаления заменяемых компонентов** и 64 MiB в `/tmp`. Установщик сохраняет конфигурации, автоматически удаляет прежние компоненты и ненужные зависимости, сохраняя зависимости других приложений. Роутер должен иметь доступ к GitHub и репозиториям пакетов OpenWrt. Зависимости, включая модули ядра, устанавливаются из feeds вашей прошивки.

После успешной установки добавьте подписку или профиль подключения, настройте маршрутизацию в LuCI и включите AnticheburNET. Для обновления всего комплекта повторите ту же SSH-команду. [Подробности установки и настройки](docs/REDMI-AX6000.md).

Для удаления полного комплекта на OpenWrt с `apk` выполните `sh install.sh --uninstall` с сохранённым скриптом. Настройки сохраняются в `/root/anticheburnet-backups/`; сервисы останавливаются, DNS восстанавливается, пакеты AnticheburNET и ненужные зависимости удаляются. Ядро sing-box, используемое другим приложением, сохраняется. [Команда удаления через SSH](docs/REDMI-AX6000.md#удаление).

## Проверки и ограничения

Backend-проверки и frontend-тесты проходят в [GitHub CI](https://github.com/m-bezrukoff/AnticheburNET/actions/runs/38143131505). Упакованные ARM64-ядра проверены под QEMU: Xray, шифрованное соединение Hysteria 2 с ECH, туннель AmneziaWG, правила HAPP и DNS. [Сборка и испытания ядер](https://github.com/m-bezrukoff/AnticheburNET/actions/runs/38138218728).

Физический AX6000, fw4/TPROXY и производительность на роутере пока не испытаны. Импорт AmneziaWG проверен на контролируемых профилях; в пользовательской смешанной подписке распознан один AWG 3.1 профиль в формате `vpn://`. Профили с `FakeDNS=true` отклоняются; для `happ://crypt...` нужна исходная HTTP(S)-ссылка провайдера. Если устройство обходит DNS роутера, применение доменных правил зависит от распознавания протокола.
