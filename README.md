# AnticheburNET

VPN, прокси и управление маршрутизацией для **OpenWrt 25.12**. AnticheburNET позволяет выбирать, какие устройства, домены и IP-адреса используют защищённое подключение, выходят в интернет напрямую или блокируются. Настройки доступны в веб-интерфейсе LuCI.

Система предназначена для всех устройств с **OpenWrt 25.12**. Поддерживаются **VLESS, Hysteria 2, XHTTP и AmneziaWG 3.1**, а также полное ядро **Xray 26.10.10**.

| Параметр | Поддерживаемая конфигурация |
| --- | --- |
| Устройства | Все устройства с OpenWrt 25.12 |
| Система | OpenWrt 25.12 |
| Интерфейс управления | LuCI |
| Поддерживаемые протоколы | VLESS, Hysteria 2, XHTTP, AmneziaWG 3.1 |
| Поддерживаемые ядра | sing-box extended, Xray 26.10.10 |

## Подключения и подписки

- **sing-box extended 1.14.1 / 2.7.2** — VLESS, Hysteria 2 и XHTTP; поддержка uTLS и Clash API.
- **Xray 26.10.10** — поддержка полного ядра Xray, включая VLESS, с сохранением нативных outbound-настроек и подключением к маршрутизации через локальный SOCKS.
- **AmneziaWG 3.1** — userspace-туннель через `/dev/net/tun`, официальный daemon и инструменты настройки. Поддерживаются параметры версии 3.1 и импорт конфигурации по HTTP(S).
- **Подписки Happ** — импорт VLESS и Hysteria 2, включая ECH, с обновлением узлов и маршрутизации из одной HTTP(S)-ссылки.

Профили AmneziaWG 3.1 в формате `vpn://` с Base64-кодированной `.conf` автоматически входят в общий список подписки на Dashboard: доступны выбор сервера, копирование ссылки и проверка задержки. Параметры 3.1 сохраняются полностью; каждый отдельный профиль работает через официальный daemon и собственный интерфейс с отдельной таблицей маршрутизации. Нужен установленный компонент AmneziaWG 3.1; служба профилей подписки входит в backend и обновляется вместе с LuCI через Check update. После установки обновите подписку. Сжатые JSON-контейнеры Amnezia `vpn://` этим импортом пока не поддерживаются.

При активном динамическом провайдере новые, изменённые и удалённые AWG-профили применяются при обновлении подписки автоматически, без Save & Apply и перезапуска sing-box. Неизменённые AWG-интерфейсы продолжают работать. Новый интерфейс сначала проходит проверку готовности; старые удаляются только после подтверждения обновления провайдера. Изменение маршрутизации или других настроек вне списка прокси по-прежнему требует применения конфигурации.

Для отдельного интерфейса AmneziaWG 3.1 также принимаются `.conf`, профили sing-box extended и Mihomo JSON/YAML с `amnezia-wg-option`, а также указанные `vpn://` ссылки внутри смешанной подписки. Если в подписке несколько профилей, нужно выбрать точное имя. Ошибка загрузки или проверки сохраняет рабочую конфигурацию. После обновления отдельного AWG-интерфейса примените настройки AnticheburNET или перезапустите сервис.

## Маршрутизация и DNS

Правила объединяются в секции: можно выбирать подключение для устройств, доменов и подсетей, задавать прямой выход или блокировку, использовать группы узлов с проверкой доступности и автоматическим выбором.

Маршрутизация Happ применяется вместе с подпиской: учитываются порядок Direct/Proxy/Block, глобальный выход, доменные и IP-правила, GeoIP/GeoSite, Remote/Domestic DNS и DnsHosts. Изменение только правил также обновляет конфигурацию. DNS сохраняет соответствие доменов и реальных IP для маршрутизации клиентских соединений; поддерживаются IPv4 и IPv6.

## Место на flash

В релизе **1.0.1** шесть APK устанавливают **31 183 666 байт файлов**. Консервативная оценка размещения — **32 080 690 байт**. В комплект входят AmneziaWG 3.1 и полные базы GeoIP/GeoSite.

Бинарники упакованы UPX, встроенные базы Xray хранятся в gzip и распаковываются в RAM. Загружаемые базы маршрутизации Happ и преобразованные rule-set также размещаются в RAM. Расход оперативной памяти зависит от правил и нагрузки.

[Измерения и сравнение способов упаковки](docs/FLASH-BUDGET.md).

## Обновление программы

В разделе «Компоненты» кнопка **«Проверить обновление»** у AnticheburNET обновляет комплект релиза для устройства: основную программу, LuCI, установленный перевод, sing-box extended, Xray и AmneziaWG. Zapret, Zapret2 и ByeDPI обновляются отдельными кнопками в карточках справа. Кнопка AnticheburNET проверяет компоненты релиза и тогда, когда основная программа уже последней версии. Отдельная карточка sing-box не отображается.

Флажок над кнопкой включает автоматическое обновление всего комплекта каждые три календарных дня в **04:00 по времени роутера**. Настройка сохраняется сразу, без перезапуска сервиса; по умолчанию она выключена. Первый запуск назначается через три календарных дня после включения. Расписание сохраняется после перезагрузки и обновления программы; если роутер пропустил назначенное время, проверка выполняется в ближайшее следующее 04:00. Актуальный комплект повторно не устанавливается.

Под флажком отображаются дата, время роутера и результат последнего автоматического запуска: обновлено, уже актуально, ошибка, выполняется или прервано. История сохраняется после перезагрузки и выключения флажка. Ручная проверка обновления её не изменяет.

Пакеты релиза проверяются по SHA256SUMS до установки. Настройки сохраняются; перед заменой пакетов создаётся резервная копия в `/root/anticheburnet-backups`. Фоновая проверка сообщает о новой версии без установки.

## Установка

Сохраните резервную копию настроек через LuCI → System → Backup на компьютер. Войдите на роутер по SSH под `root` и выполните **одну команду**:

```sh
( f="$(mktemp /tmp/anticheburnet-install.XXXXXX)" || exit 1; trap 'rm -f "$f"' EXIT; wget -T 30 -O "$f" https://raw.githubusercontent.com/m-bezrukoff/AnticheburNET/main/install.sh && sh "$f" )
```

При запуске установщик предложит выбрать `1) install` или `2) uninstall` (также можно ввести слово `install` или `uninstall`). После выбора `install` он спросит язык интерфейса: **`1) English` — по умолчанию**, `2) Русский`. Enter выбирает английский; неверный номер повторяет вопрос. Выбранный язык сохраняется в настройке `luci.main.lang` и применяется ко всему интерфейсу LuCI. Затем установщик автоматически скачает последний релиз с GitHub, проверит SHA-256 и установит **весь комплект**: AnticheburNET, LuCI с пакетом русского перевода, sing-box extended (VLESS/Hysteria 2/XHTTP), Xray 26.10.10 и AmneziaWG 3.1. Выбор компонентов и ручное скачивание не требуются. Опции `sh install.sh --install` и `sh install.sh --uninstall` пропускают выбор действия; при установке вопрос о языке остаётся, а при отсутствии ввода используется английский. Удаление не спрашивает язык.

Нужна установленная OpenWrt 25.12 с `apk`, свободное место в overlay для установки компонентов и 64 MiB в `/tmp`. Готовый полный комплект APK поддерживает `mediatek/filogic` и `mediatek/mt7622` с архитектурой `aarch64_cortex-a53`; обе платформы используют одни и те же пакеты программ. Для других платформ нужен соответствующий комплект компонентов. Общий режим `sh install.sh --generic` устанавливает AnticheburNET/LuCI с выбором sing-box. Установщик сохраняет конфигурации, автоматически удаляет прежние компоненты и ненужные зависимости, сохраняя зависимости других приложений. Устройство должно иметь доступ к GitHub и репозиториям пакетов OpenWrt. Зависимости, включая модули ядра, устанавливаются из feeds вашей прошивки.

После успешной установки добавьте подписку или профиль подключения, настройте маршрутизацию в LuCI и включите AnticheburNET. Для обновления всего комплекта повторите ту же SSH-команду. [Подробности установки и настройки](docs/OPENWRT-25.12.md).

Для удаления полного комплекта на OpenWrt с `apk` выполните `sh install.sh --uninstall` с сохранённым скриптом. Настройки сохраняются в `/root/anticheburnet-backups/`; сервисы останавливаются, DNS восстанавливается, пакеты AnticheburNET и ненужные зависимости удаляются. Ядро sing-box, используемое другим приложением, сохраняется. [Команда удаления через SSH](docs/OPENWRT-25.12.md#удаление).

## Проверки и ограничения

Backend-проверки и frontend-тесты проходят в [GitHub CI](https://github.com/m-bezrukoff/AnticheburNET/actions/runs/38143131505). Упакованные ARM64-ядра проверены под QEMU: Xray, шифрованное соединение Hysteria 2 с ECH, туннель AmneziaWG 3.1, правила HAPP и DNS. [Сборка и испытания ядер](https://github.com/m-bezrukoff/AnticheburNET/actions/runs/38138218728).

Работа fw4/TPROXY и производительность на физических устройствах пока не испытаны. Импорт AmneziaWG 3.1 проверен на контролируемых профилях; в пользовательской смешанной подписке распознан один AWG 3.1 профиль в формате `vpn://`. Профили с `FakeDNS=true` отклоняются; для `happ://crypt...` нужна исходная HTTP(S)-ссылка провайдера. Если устройство обходит DNS роутера, применение доменных правил зависит от распознавания протокола.
