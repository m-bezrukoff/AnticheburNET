# Упаковка компонентов и размер на flash

`/tmp` и `/var/run` в стандартном OpenWrt находятся в RAM. В комплекте сохранены sing-box с Hysteria 2, штатный Xray 26.10.10, AmneziaWG 3.1 и обе полные базы GeoIP/GeoSite.

## Проверенные способы упаковки

| Способ | Результат и условия | Решение |
| --- | --- | --- |
| Go `-trimpath -s -w`, static ARM64 | Удалены отладочные символы и пути сборки; требуемые протоколы сохранены. Без дополнительной упаковки компоненты занимали около 114 MiB. | Применён |
| UPX 5.2.1, `--best --lzma` | sing-box примерно 10,8 MB, AWG с tools примерно 1,8 MB. Все три Go-бинарника проверяются `upx -t` и запускаются в протокольных тестах QEMU. | Применён |
| Только сжатие APK | Уменьшает загрузку, но APK распаковываются при установке. | Используется для передачи |
| Сжатие UBIFS / firmware SquashFS | Зависит от разметки и образа прошивки. Установка обычных APK не переносит их автоматически в read-only SquashFS. | Не используется для оценки размещения |
| Удаление gVisor, дополнительных протоколов, Xray или AWG | Сокращает бинарники, но меняет возможности проекта. | Не понадобилось |
| Сжатое хранение geodata и распаковка в RAM | На flash остаётся только архив; Xray получает полные проверенные `.dat` в RAM. | Применено |
| Отдельный SquashFS-образ geodata | Экономит flash и допускает чтение без полной распаковки, но требует поддержки loop и SquashFS в ядре/feeds роутера. | Альтернатива |

## Сравнение полного GeoIP/GeoSite

Измерения выполнены на двух файлах из официального архива Xray, проверенного SHA256. Ничего из баз не удалено. Единицы ниже — десятичные MB.

| Формат | Размер на flash | Что нужно на роутере |
| --- | ---: | --- |
| Без сжатия | 27 724 084 байт / 27,72 MB | Обычные файлы |
| gzip | 7 142 457 байт / 7,14 MB | Штатный BusyBox tar; около 27,72 MB для файлов в RAM |
| bzip2 | 6 572 280 байт / 6,57 MB | Декодер bzip2 и файлы в RAM |
| xz | 4 106 156 байт / 4,11 MB | Декодер xz, RAM для словаря и файлов |
| zstd | 4 935 157 байт / 4,94 MB | Декодер zstd и файлы в RAM |
| SquashFS + xz | 5 222 400 байт / 5,22 MB | Loop/SquashFS в ядре, mount с правами root |

Выбран gzip: распаковка не добавляет пакеты декодера и не зависит от модулей ядра. xz даёт ещё около 3 MB экономии, но для этой сборки дополнительная зависимость не требуется. Расход RAM для geodata и рабочей памяти процессов на физических устройствах ещё не измерен.

## Контроль установленного размера

`components/build.sh` получает `installed-size` из метаданных **всех шести готовых APK**, суммирует payload и строит консервативную оценку с дополнительным блоком 4 KiB на каждый entry. Оба значения должны быть не больше **35 000 000 байт**; иначе публикация artifact не выполняется.

Точные результаты каждой сборки лежат в `installed-sizes.txt` и `packing-comparison.csv` рядом с APK. Сравнение сжатия запускается заново для закреплённых входных файлов, поэтому увеличение upstream geodata не обходит контроль бюджета.

Для релиза 1.0.0: **31 144 154 байта файлов всех шести APK**, **32 016 602 байта** по консервативной оценке размещения с дополнительным блоком 4 KiB на entry. Полный комплект включает AmneziaWG 3.1. [Успешная сборка и протокольные испытания](https://github.com/m-bezrukoff/AnticheburNET/actions/runs/38092351620), исходники пакетов `b0ef4c67fb8f4b29620cd0b1a07dfac0448bb7ec`.

Для релиза 1.0.1 с импортом подписок Happ/AWG и маршрутизацией: **31 183 666 байт файлов всех шести APK**, **32 080 690 байт** по той же консервативной оценке. DAT провайдера и преобразованные GeoIP/GeoSite rule-set находятся только в `/tmp/anticheburnet-happ-<секция>` (RAM), а в конфигурации sing-box сохраняются ссылки на них. [Успешная сборка и испытания](https://github.com/m-bezrukoff/AnticheburNET/actions/runs/38126196363), исходники пакетов `94d9f9d0d04b4443fdb9c0d4104feeb36218a417`.

При первом запуске `anticheburnet-xray-assets` проверяет распакованные базы по SHA256, помещает их только в `/var/run/anticheburnet-xray/assets`, а следующие запуски используют тот же cache. После reboot cache создаётся заново. Проверки запускают Xray с настоящими правилами `geosite:cn` и `geoip:private`, затем выполняют передачу данных. Flash не содержит второй распакованной копии баз.

Резервные копии настроек сохраняйте на компьютере. При [установке одной SSH-командой](OPENWRT-25.12.md#установка) установщик автоматически проверяет свободное место на flash и в `/tmp`, скачивает пакеты в `/tmp` и удаляет временные файлы при завершении. Размер пользовательских конфигураций, дополнительно установленные программы и их зависимости зависят от текущего устройства; для самостоятельной проверки доступен `df -h /overlay /tmp`. Эти измерения не являются замером фактического размещения на физическом роутере.

## Эмуляция ARM64

CI использует QEMU 8.2.2 с закреплённым commit и добавленной передачей `SO_MARK` ядру Linux: штатный QEMU user mode эту операцию не реализует. Пробный ARM64-бинарник устанавливает и считывает настоящую IPv4/IPv6 socket mark, затем AWG применяет конфигурацию через рабочий importer с той же меткой. Изменение относится только к тестовому эмулятору; на роутер QEMU не устанавливается. Для локального повторения используйте `bash components/build-test-emulator.sh` перед `components/build.sh`; зависимости приведены в workflow.
