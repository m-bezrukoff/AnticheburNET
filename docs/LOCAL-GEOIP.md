# Локальное определение страны серверов

Опция «По локальной базе GeoIP» определяет страны серверов подписки на самом
роутере. Внешний сервис `api.country.is` больше не вызывается. Внутреннее значение
UCI `country_is` сохранено для совместимости: существующие фильтры Dashboard,
URLTest и Priority автоматически используют локальную базу без перенастройки.
Метод по флагу в названии узла остаётся доступным и используется по умолчанию.

В backend включён неизменённый снимок DB-IP Country Lite за октябрь 2026 года
для IPv4 и IPv6. Он хранится сжатым в `/usr/share/anticheburnet/geoip` (около
3,93 MiB на flash), проверяется по SHA256 и распаковывается при первом обращении
в `/var/run/anticheburnet/geoip` (около 7,96 MiB RAM). Последующие обращения
используют готовую копию. Чтение MMDB выполняет `mmdblookup` из зависимости
OpenWrt `libmaxminddb`; Xray для этого не нужен. Оба способа сборки backend
(Makefile OpenWrt и `build.sh`) включают данные, helper и зависимость.

При определении страны IP-адреса узлов не отправляются провайдеру геолокации.
Для узлов, заданных доменным именем, остаётся обычный DNS-запрос к настроенному
bootstrap DNS: без разрешения имени определить IP невозможно. Для литералов
IPv4/IPv6 DNS не вызывается. Приватные, зарезервированные и неизвестные адреса
не получают выдуманную страну. При отсутствии или повреждении базы сетевого
резервного способа определения страны нет.

Кэш привязан к серверу, поэтому переживает изменение outbound-тега. Новый снимок
базы инвалидирует кэш с предыдущей известной ревизией. Старый кэш без отметки
ревизии сохраняется при первом переходе для совместимости.

База обновляется с пакетами AnticheburNET; фоновой загрузки с роутера нет.
Для обновления снимка сопровождающий заменяет `country.mmdb.gz`, пересчитывает
`country.sha256`, проверяет IPv4/IPv6 через `tests/geoip_database.sh` и обновляет
дату, размеры и хеши в сопровождающем README. Данные Lite имеют ограниченную
точность: страна базы не гарантирует физическое местоположение оборудования.

Данные: [IP Geolocation by DB-IP](https://db-ip.com), лицензия
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
[Источник и условия распространения](https://db-ip.com/db/download/ip-to-country-lite).
Атрибуция размещена в интерфейсе и в каталоге базы; ссылка не загружается
автоматически и сама по себе не отправляет запросов к DB-IP.

Проверки: `bash tests/country_detection.sh` (ucode),
`bash tests/geoip_database.sh` (mmdblookup),
`bash tests/package_contract.sh`, `bash tests/luci_localization.sh`.

Локальная проверка на Windows: сценарий country_detection выполнен интерпретатором
ucode/WASM с перехваченными границами запуска процессов; совместимость старых
фильтров проверена генератором URLTest/Priority. Настоящая MMDB прочитана независимым
Go-reader из локального кэша зависимостей. Проверены распаковка, SHA256, повреждённая
замена, параллельные читатели и дерево backend-пакета. В Linux CI тест использует
штатный `mmdblookup` из пакета `mmdb-bin`. Проверка на работающем OpenWrt и сборка
полных APK/IPK в этом изменении не выполнялись.
