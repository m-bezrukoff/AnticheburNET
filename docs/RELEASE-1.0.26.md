# AnticheburNET 1.0.26

Restores the original LuCI application design and native theme controls. The Sections tab retains the HAPP profile, rule and resource visualization while inheriting the theme's system font, including rule lists.

The routing strategy selector is wider so the complete selected strategy label remains visible on desktop layouts.

Dashboard and Components now use the full width of their parent containers. Optional component cards use their content width without wrapping text, while the AnticheburNET card fills the remaining space.

Help icons beside form descriptions are two pixels smaller and vertically centered on the first line of text, including descriptions that wrap.

Application, LuCI and Russian translation packages are rebuilt. Backend behavior and ARM64 component binaries are unchanged from 1.0.25. Installing this release is a separate action from publishing it.
