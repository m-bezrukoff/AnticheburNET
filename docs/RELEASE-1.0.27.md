# AnticheburNET 1.0.27

The Sections table now appears immediately after Routing strategy, before the HAPP rules and resources panel.

All text inside HAPP rules and resources inherits the active LuCI theme's base font and line height. Headings use the base text size, panels and rule lists have compact spacing, and the Refresh button uses the native theme control. The compact layout also applies on narrow screens.

Application, LuCI and Russian translation packages are rebuilt. Backend behavior and ARM64 component binaries are unchanged from 1.0.26. Installing this release is a separate action from publishing it.
